# 베롱이 🌸 — 나만의 AI 비서

핸드폰에서 돌아가는 나만의 전담 비서 에이전트.
일정을 관리해주고, 실수를 미리 막아주고, 뭐든 정리해주고, 대화가 되는 AI.

## 기능

| 탭 | 하는 일 |
|---|---|
| 💬 베롱이 | 대화하면서 일정 등록, 메모 저장, 조회까지 베롱이가 직접 처리 |
| 📅 일정 | 일정 목록, 완료 체크, 삭제, 수동 추가. 알림(리마인더) 자동 예약 |
| 📝 메모 | 저장된 메모 목록, 검색, 수동 추가 |
| ⚙️ 설정 | API 키 등록, 두뇌(모델) 선택, 호칭 설정 |

- **실수 방지**: 일정이 30분 안에 겹치면 베롱이가 경고해요.
- **알림**: 일정마다 "N분 전 알림"이 아이폰 알림으로 와요.
- **프라이버시**: 일정·메모·대화는 전부 핸드폰 안에만 저장. API 키는 iOS 키체인에 보관.

## 아이폰에서 실행하는 법 (무료)

1. **아이폰에서** App Store에서 **Expo Go** 앱을 설치
2. **컴퓨터에서** 이 폴더에서 실행:
   ```
   npx expo start
   ```
3. 터미널에 뜨는 **QR 코드를 아이폰 카메라로 스캔** → Expo Go에서 베롱이가 열림
   (컴퓨터와 아이폰이 **같은 와이파이**에 있어야 해요)

## API 키 발급 (베롱이 두뇌 연결)

1. https://console.anthropic.com 접속 → 가입/로그인
2. **API Keys** 메뉴 → **Create Key** → 키 복사 (`sk-ant-...`)
3. 결제 수단 등록 후 크레딧 충전 (최소 $5면 한참 씀)
4. 베롱이 앱 → **설정 탭** → 키 붙여넣기 → 저장

### 비용 팁
- **절약 모드(Haiku)**: 대화 1번에 약 1~3원. 일상 비서 용도로 충분
- **똑똑 모드(Sonnet)**: 대화 1번에 약 10~30원. 더 자연스럽고 똑똑함

## 나중에 "진짜 앱"으로 만들려면

Expo Go 없이 홈 화면에 베롱이 아이콘만 띄우고 싶어지면:
1. Apple Developer 계정 가입 (연 $99)
2. `npx eas-cli build --platform ios` 로 클라우드에서 앱 빌드 (맥 없어도 됨)
3. TestFlight로 설치

## 개발 메모

- Expo SDK 57 / React Native / TypeScript

  `src/screens/` (화면 4개), `src/notifications.ts` (알림), `src/storage.ts` (저장)
- 검사: `npx tsc --noEmit`, `npx expo-doctor`
